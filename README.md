
## 1. Definições Principais:
- **Temática:** E-commerce de tênis focado em esportes e alta performance.

- **Nome do Projeto:** Maratona

- **Identidade Visual:** Cores vibrantes e dinâmicas, remetendo a velocidade e energia.

- **Frontend:** React com TypeScript.
  - **Arquitetura:** Layer-Based (Baseado em camadas)
  - **Padrões de Projeto:** Custom Hooks, Context Provider e Container/Presenter
  - **Hospedagem:** Vercel

- **Backend:** Node.js com Express.js
  - **Arquitetura:** Layered Architecture (Controller-Service-Repository)
  - **Padrões de Projeto:** Dependency Injection, Singleton e DTO
  - **Hospedagem:** Render
  - **Cache:** Redis

- **Banco de Dados:** PostgreSQL
  - **Hospedagem:** Neon
